# EDGEmods Example

This folder shows what a mod's repository looks like to EDGEmods. The EDGEmods publishing form writes these files for you; this example exists so the format can be checked and read.

| File | What it is |
|---|---|
| `edgemods.json` | The metadata: name, short description, version, type, tags, images, release files and requirements |
| `README.md` | This page. EDGEmods renders it as the mod's page |
| `images/` | The card image (2:1, 1280 × 640) and the gallery |

The mod's downloads are not in the repository. They are attached to a GitHub release tagged `v1.0.0`, with the file names listed in `edgemods.json`.

## Installing

1. Install the main file.
2. Choose one body: A or B. They replace the same thing, so only one can be installed.
3. Add the extras if you want them.

## Requirements

- [ArchiveXL](https://www.nexusmods.com/cyberpunk2077/mods/4198)
- EDGEmods Example Core 1.2.0 or later (made up for this example)
